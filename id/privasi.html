Kebijakan Privasi · Dukungan

Terakhir diperbarui: 4 Juni 2026

Kami di aplikasi Elif (“Elif”, “kami”) peduli pada privasi Anda. Teks ini menjelaskan data apa yang kami proses dan mengapa, serta apa saja hak Anda. Dengan menggunakan Elif, Anda menyetujui ketentuan ini.

1) Data yang kami kumpulkan

  • Lokasi: digunakan untuk menghitung waktu salat dan arah kiblat. Lokasi Anda diproses hanya di perangkat Anda dan tidak pernah dikirim ke server kami.
  • Izin notifikasi: digunakan untuk notifikasi azan dan pengingat.
  • Detail akun (opsional): jika Anda mendaftar untuk pencadangan cloud, alamat email dan kata sandi Anda disimpan dengan aman.
  • Data ibadah/kemajuan (opsional): jika Anda masuk, pelacakan salat, zikir dan target Anda dicadangkan ke cloud.
  • Kiriman dinding doa Anda: doa yang Anda bagikan dapat dilihat pengguna lain.
  • Data kerusakan/diagnostik: jika aplikasi mengalami kerusakan, informasi teknis anonim dapat dikumpulkan untuk memperbaiki kesalahan tersebut.

2) Bagaimana kami menggunakan data

Kami menggunakan data Anda hanya untuk menjalankan aplikasi (waktu salat, kiblat, notifikasi, pencadangan, dinding doa) dan untuk meningkatkannya. Kami tidak menjual data Anda dan tidak membagikannya kepada pihak ketiga untuk tujuan periklanan.

3) Layanan pihak ketiga

  • Supabase: hosting aman untuk data akun dan pencadangan cloud.
  • Sentry: laporan kerusakan dan diagnostik kesalahan.

Layanan ini memproses data Anda hanya atas nama kami.

4) Penyimpanan dan penghapusan

Data Anda disimpan selama akun Anda aktif. Di dalam aplikasi Anda dapat menghapus akun beserta seluruh data cloud Anda (termasuk cadangan dan kiriman dinding doa) secara permanen melalui Pengaturan → Akun → “Hapus akun”. Tindakan ini tidak dapat dibatalkan.

5) Hak Anda

Anda berhak mengakses, memperbaiki dan menghapus data Anda, serta menolak pemrosesannya. Pengguna di Turki juga memiliki hak yang diberikan oleh Undang-Undang No. 6698 tentang Perlindungan Data Pribadi (KVKK). Anda dapat menghubungi kami di alamat email di bawah untuk permintaan semacam itu.

6) Privasi anak-anak

Elif ditujukan untuk khalayak umum. Kami tidak dengan sengaja mengumpulkan data pribadi dari anak-anak di bawah usia 13 tahun.
